# ΕΚΑΒ 1 → ΕΚΑΒ Σπουδή V2: αρχειοθήκη μεταφοράς

Το περιεχόμενο αυτού του φακέλου προέρχεται από το δημόσιο repository του ΕΚΑΒ 1, ως ξεχωριστό στιγμιότυπο για τη V2. **Δεν εκτελείται** αυτόματα, **δεν αλλάζει** το interface και δεν μοιράζεται λογαριασμούς ή πρόοδο.

Οι ήδη ενεργοποιημένες εκπαιδευτικές εγγραφές συγχρονίζονται χωριστά μέσω του scripts/import-v1-data.py στην παραγωγή της V2. Οι υπόλοιπες σελίδες, αρχεία, σενάρια και εκπαιδευτικοί μηχανισμοί παραμένουν εδώ μέχρι να δοκιμαστούν και να ενσωματωθούν.

Πλήρη στοιχεία και αιτίες εξαιρέσεων: MIGRATION_MANIFEST.json.
Δεδομένα προόδου χρηστών, credentials, backend και αδειοδοτημένο ή αβέβαιων δικαιωμάτων PDF/σκαναρισμένο περιεχόμενο δεν μεταφέρονται.
