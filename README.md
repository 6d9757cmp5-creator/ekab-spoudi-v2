# ΕΚΑΒ Σπουδή V2 — ανεξάρτητη Safari Web/PWA έκδοση

**Δημόσια ιστοσελίδα:** https://6d9757cmp5-creator.github.io/ekab-spoudi-v2/

**Ανεξάρτητο αποθετήριο:** https://github.com/6d9757cmp5-creator/ekab-spoudi-v2

## Τι είναι

Αυτή είναι μια web/PWA **μεταφορά**, βασισμένη στο περιεχόμενο και στα Kotlin/Jetpack Compose layouts του αυθεντικού ZIP της εφαρμογής, και στις οθόνες που παρουσιάστηκαν στο βίντεο. Δεν αποτελεί αυτόματη μεταγλώττιση Kotlin σε JavaScript, ούτε εγγύηση πιστού 1:1 για όλες τις λειτουργίες. Ο αυθεντικός Android κώδικας παραμένει ξεχωριστός.

- Αρχική/MENTOR OS και κάτω πλοήγηση με χρωματική παλέτα και διάταξη που μιμούνται την Android έκδοση.
- 20 μαθήματα ΣΑΕΚ με ύλη και τοπική παρακολούθηση ολοκλήρωσης.
- 314 ερωτήσεις ΕΟΠΠΕΠ με απαντήσεις και επανάληψη.
- 70 εκπαιδευτικές καρτέλες φαρμακολογίας, 5 σεμινάρια, επαγγελματικά στοιχεία, πρακτική εξέταση και επαφές από το ZIP.
- MENTOR OS: δείγματα ΗΚΓ, εκπαιδευτικές αποστολές, MCI triage, καρτέλες εξοπλισμού, κατάλογος βιβλιογραφικών πηγών και κάρτες ειδικοτήτων.

**Περιορισμοί:** Ζωντανός AI καθηγητής/φωνητική συνομιλία, πραγματική 3D ανατομία και πλήρη native υποσυστήματα δεν λειτουργούν στη Safari έκδοση ακόμη. Σημαίνονται καθαρά ως μη συνδεδεμένα/εκκρεμή. Η πληροφορία είναι για εκπαίδευση, όχι κλινική καθοδήγηση.

## Safari / εγκατάσταση

Στο iPhone ανοίξτε τη δημόσια HTTPS διεύθυνση με **Safari**, πατήστε **Κοινή χρήση → Προσθήκη στην οθόνη αφετηρίας**. Η εφαρμογή ανοίγει με δικό της εικονίδιο και υποστηρίζει βασικό offline cache (μετά την πρώτη online φόρτωση). Τα δεδομένα προόδου κρατούνται **τοπικά** ανά browser/εγκατάσταση και δεν συνδέονται με την αρχική εφαρμογή.

Για κανονικό iOS `.ipa` απαιτείται ξεχωριστό Xcode project και κατάλληλο Apple signing/provisioning. Η PWA δεν είναι αρχείο IPA.

## Ανεξαρτησία και ασφάλεια

Δεν περιλαμβάνει το Firebase του πρώτου project, δεν χρησιμοποιεί το API του πρώτου repo και δεν τροποποιεί την αρχική εφαρμογή. Τα δεδομένα αποθηκεύονται στο δικό τους `localStorage` κλειδί `ekab-spoudi-v2-preview-local-2026` στο GitHub Pages origin και διαχωρίζονται από την αρχική εφαρμογή.

Καμία επιστημονική πιστοποίηση δεν τεκμαίρεται από την εισαγωγή αρχείων. Μην χρησιμοποιείται ως πρωτόκολλο παροχής πραγματικής επείγουσας φροντίδας.
